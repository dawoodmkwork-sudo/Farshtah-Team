Features

Everything you need to animate R6

Built for fight moves, emotes and everything in between. Small enough to learn in a minute.

Keyframes that flow

34 easings: smooth, spline, and ten curve families (back, elastic, bounce and more), each with in, out and in-out.

Box select, copy, paste

Drag a box over keys or body parts. Copy keyframes and paste them anywhere, or mirrored onto the other side.

Video references

Drop in a GIF or MP4 and step through it frame by frame, overlay it on the rig, and lock it to your timeline.

Test it like in game

Walk around with WASD and a Roblox-style camera, and trigger your animation with blocks like "When E is pressed".

Your rig, your look

Six looks plus colours and shapes for every part: blocky, rounded, mannequin, ball head, toon or smooth shading.

Build props

Model swords, bats or anything else from simple shapes, then put them in the rig's hand and adjust the grip.

Themes and clips

Fourteen themes (six animated), custom image, GIF or video backgrounds with effects, and a built-in MP4 clip recorder.

Straight into Studio

One click copies a prompt for Claude, or a script for the Command Bar. It checks itself before it builds anything.

Test mode

Feel the timing before it's in your game

Hit Test and you're in a little Roblox world. Your animation plays on top of a Roblox-style idle and walk, blending in and out just like an Action track.

  • WASD to move, Space to jump, right-drag to look, scroll to zoom
  • Blocks decide the rest: When E is pressed → Play animation
  • Set WalkSpeed, JumpPower, Camera FOV, Gravity or the animation speed
Props

Swing what you'll actually hold

Build a model from blocks, balls, cylinders, cones, wedges and rings, make parts glow, and give it to any body part. It's saved with each animation.

  • Move, turn and scale with the gizmo, or type exact sizes
  • Mirror, duplicate and undo while you build
Make it yours

Themes, backgrounds and a clip recorder

Pick a theme (Aurora, Synthwave, Starfield, Embers, Matrix and Liquid are animated) or put your own image, GIF or video behind the rig, with blur, tint, grain and more. Then record an MP4 straight from the 3D view.

  • Drag the panels to any size, or move them around
  • Focus mode: just the 3D view, full screen
Install

Up and running in a minute

No accounts, no extra downloads. Everything it needs is in the zip.

Download and unzip

Grab the zip above, right-click it and choose Extract All.

Run the installer

Double-click Install Farshtah.cmd. If Windows warns you, click More info, then Run anyway.

Start animating

Farshtah opens in its own window. Next time, use the shortcut on your Desktop or in the Start menu.

Your work is saved in Documents\Farshtah. To remove the app: Start menu → Farshtah → Uninstall (your files stay).

Into Roblox Studio

From Farshtah to your game in one paste

Open the Clip tab, choose where it should go, and copy.

Copy for Claude

Paste it to a Claude that's connected to Roblox Studio. It runs the script and tells you what it made.

Please add this animation to my Roblox Studio place. It's "KatanaCutSample", made in Farshtah (an R6 animator). Use the Roblox Studio MCP tool execute_luau with datamodel_type "Edit" and run the Luau script below…

Copy script

No Claude? Paste the script into Studio's Command Bar (View → Command Bar). It prints what it did to Output.

Farshtah: checksum ok (69.8092) | bake matches the page (worst 5.2e-07) | ServerStorage.AnimatorImports.KatanaCutSample: 61 keyframes, 1.000 s

The script checks its own data and compares its bake with Farshtah's before it creates anything, and backs up an older animation with the same name.

FAQ

Questions

Is it really free?

Yes. Farshtah is open source under the MIT license, and the full source code is in the download's source folder.

Why does Windows warn me about the installer?

The installer isn't code-signed (that costs money every year), so Windows doesn't know who made it. It only copies files into your user folder and makes shortcuts. You can read every line in the zip.

What do I need?

Windows 10 or 11. Farshtah brings its own copy of Node.js and shows itself in Microsoft Edge, which comes with Windows. The first launch needs internet to load the 3D view; after that it's usually cached.

Does it do R15?

No, Farshtah is made for R6 rigs.

Mac or Linux?

Not yet: the installer is Windows-only.

Where are my animations?

In Documents\Farshtah, as plain files: animations, references, backgrounds, models, settings and recorded clips. Updating or uninstalling never deletes them.

How do I update?

Download the new zip and run Install Farshtah.cmd again. Your work stays where it is.
